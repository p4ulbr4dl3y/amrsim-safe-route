# AMR SafeRoute - Автоматизированное рабочее место оператора (АРМ)

Веб-приложение для диспетчеризации, мониторинга телеметрии, аудита безопасности и анализа прогонов автономных мобильных платформ в рамках симулятора `amr-sim 0.2` (Кейс «Безопасный маршрут»).

Реализация интерфейса закрывает требования критерия оценки **О3 (Рабочее место оператора, 15 баллов)**.

---

## 1. Функциональные возможности

- **обзорный мониторинг**:
  - сводка ключевых KPI в виде статичных информационных карточек (общий балл, выполненные доставки, инциденты безопасности, ошибка оценки позы);
  - фиксированная мини-карта площадки с автоматической подгонкой `fit-to-bounds`: весь периметр склада виден целиком, колесико мыши свободно скроллит страницу без изменения масштаба карты;
  - график профиля скорости, лента событий и состояние контроллера;
- **интерактивная 2D-карта площадки**:
  - отображение векторных полигонов склада (проезжая часть `drivable`, здания и стены `buildings`, запретные зоны `forbidden`, зоны ограничения скорости `speed_limit`, пешеходные переходы `crossing`, точки доков `warehouse`, `shop_a`, `shop_b`, `charger`);
  - визуализация истинной позы робота с вектором ориентации и фантома оценки позы `pose_est` с вектором расхождения;
  - динамическая отрисовка пешеходов с векторами скорости и кругами безопасности (радиус 3.0 м);
  - лучи лидара и исторический след траектории;
  - поддержка панорамирования, масштабирования, центрирования по роботу и управления видимостью слоев;
- **воспроизведение телеметрии**:
  - плеер на базе `requestAnimationFrame` с таймером высокой точности `performance.now()`;
  - честное масштабирование скоростей: 0.1x, 0.5x, 1x, 2x, 5x, 10x (10x строго в 2 раза быстрее 5x, шаг до 100 тиков/с);
  - интерактивный таймлайн с маркерами нарушений и скраббером;
  - инспектор телеметрии: линейная и угловая скорость ($v, w, cv, cw$), статус (`moving`, `arrived`, `waiting`, `lost`, `estop`), текстовая причина замедления или остановки (`note`), дистанции до людей (`hum`) и препятствий (`obj`);
- **реестр штрафов и инцидентов**:
  - карточка математической формулы регламента для каждого типа нарушения в формате KaTeX LaTeX;
  - фильтрация по типам нарушений и стоимости штрафа, полнотекстовый поиск;
  - быстрый переход к тику нарушения на карте с автоматическим замедлением;
  - экспорт журнала инцидентов в CSV (с добавлением UTF-8 BOM для корректного открытия в Excel) и JSON;
- **журнал миссий и доставок**:
  - контроль точек погрузки и разгрузки, дедлайнов, эталонных дистанций;
  - анализ точности удержания в доке (`max_hold_dist` при допуске $\text{tol} \le 0.20$ м);
  - диаграмма сопоставления фактического времени с эталонным и дедлайном;
- **аналитика и скоринг**:
  - математически строгое оформление формул KaTeX LaTeX для всех 6 блоков регламента:
    $$S_{\text{total}} = \max\Bigl(0,\; \sum_{i=1}^{5} S_i + S_{\text{col}}\Bigr)$$
  - радарная диаграмма показателей по 6 осям;
  - метрики вычислительного бюджета контроллера (`step_time_ms`, порог 5 мс, время прогона);
  - аудит песочницы (`sandbox_violations`, лог `stderr`);
- **центр запуска симулятора**:
  - конфигурация сценария, контроллера и seed;
  - запуск реальной симуляции через API (`POST /api/run`);
  - терминальный вывод симулятора в реальном времени и кнопка перехода в плеер по завершении.

## 2. Архитектура маршрутизации

Приложение построено как SPA с хэш-маршрутизацией и поддержкой query-параметров.

| Маршрут | Модуль | Назначение |
|---|---|---|
| `#/dashboard` | `DashboardPage` | Общий мониторинг и обзорный план склада. |
| `#/replay` | `ReplayPage` | Студия телеметрии, 2D-карта и таймлайн воспроизведения. Принимает параметры: `t` (время), `x`, `y` (координаты центровки), `mission`, `scenario`. |
| `#/episodes` | `EpisodesPage` | Детальный аудит инцидентов и формулы штрафов. |
| `#/missions` | `MissionsPage` | Журнал транспортных задач и удержания в доках. |
| `#/analytics` | `AnalyticsPage` | Разбор счета в LaTeX, радарная диаграмма и выгрузка отчетов. |
| `#/runner` | `RunnerPage` | Интерфейс конфигурации и запуска симулятора. |

## 3. Стек технологий

- **фреймворк**: React 19 (TypeScript 5.7);
- **сборщик**: Vite 6;
- **стилизация**: Tailwind CSS 3;
- **рендеринг карты**: HTML5 Canvas API (аппаратное ускорение через 2D Context);
- **математическая типографика**: KaTeX (`katex`, `@types/katex`);
- **тестовый раннер**: Vitest 3, `@testing-library/react`, `jsdom`;
- **иконки**: Lucide React.

---

## 4. Модель данных и Server-Driven UI

АРМ подключен к SDUI бэкенду через централизованный клиент `src/api/client.ts`:
- загрузка готовых моделей отображения с эндпоинтов `/api/ui/*` (`dashboard`, `replay`, `episodes`, `missions`, `analytics`);
- отказоустойчивость: если бэкенд временно не запущен, клиент автоматически переключается на предгенерированные данные из `src/mock/` без сбоев интерфейса.

## 5. Установка, сборка и тестирование

### Шаги установки
```bash
cd frontend
npm install
```

### Запуск тестов (46 тестов Vitest)
```bash
npm test
```
Тестовый набор покрывает:
- `test_client.test.ts`: методы API-клиента, фоллбэки, обработку ошибок 404/500, CSV URL;
- `test_latex.test.tsx`: рендеринг KaTeX формул, инлайн и блок-режимы, спецсимволы регламента;
- `test_pages.test.tsx`: рендеринг страниц Dashboard, Episodes, Missions, Analytics;
- `test_replay.test.ts`: математика плеера, масштабирование скорости (1x, 2x, 5x, 10x), скраббинг;
- `test_map_canvas.test.ts`: алгоритм fit-to-bounds, проекция координат, изоляция мини-карты.

### Запуск сервера разработки
```bash
npm run dev
```
Приложение доступно по адресу `http://localhost:3000`.

### Сборка для продакшена
```bash
npm run build
```
Результат сборки помещается в каталог `dist/` (0 ошибок компиляции).
