# Рабочее место оператора (АРМ) — Dreamteam 4.0

Интерфейс оператора для мониторинга, разбора телеметрии, инцидентов и запуска симуляций (критерий О3).

## Быстрый запуск (1 команда)

Из корня репозитория:
```bash
python arm/server.py --port 8000
```
Затем открыть в браузере: `http://localhost:8000`

> **Примечание:** Сервер написан на стандартной библиотеке Python (`http.server`) и автоматически раздает предсобранный SPA интерфейс из `arm/frontend/dist`. Сторонние пакеты не требуются.

## Возможности АРМ (Критерий О3 — 15 баллов):
- **Dashboard**: сводка KPI, статус прогонов, целевая функция и штрафы.
- **Replay**: интерактивный плеер тиков с картой, позой робота, пешеходами, скоростью и переключением слоев.
- **Episodes**: журнал штрафных эпизодов с фильтрацией, формулами LaTeX и экспортом в CSV.
- **Missions**: журнал перевозок с допусками по времени и позиционированию.
- **Analytics**: радарный график по 6 блокам скоринга, аудит песочницы и вычислительного бюджета.
- **Runner**: запуск сценариев симуляции через API симулятора amrsim.

## Разработка фронтенда:
```bash
cd arm/frontend
npm install
npm run dev     # Режим разработки
npm test        # 87 автоматических тестов Vitest
npm run build   # Сборка в arm/frontend/dist
```
