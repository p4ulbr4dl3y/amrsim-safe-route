# AMR SafeRoute — Автоматизированное рабочее место оператора

Веб-приложение для диспетчеризации, мониторинга телеметрии, аудита безопасности и анализа прогонов автономных мобильных платформ (AMR) в рамках симулятора `amr-sim 0.2` (Кейс «Безопасный маршрут»).

Реализация интерфейса закрывает требования критерия оценки **О3 (Рабочее место оператора, 15 баллов)**.

---

## 1. Функциональные возможности

- **Обзорный мониторинг**: сводка ключевых метрик (Total Score, выполненные доставки, инциденты безопасности, ошибка оценки позы), график профиля скорости, лента событий и состояние контроллера.
- **Интерактивная 2D-карта площадки (Canvas Engine)**:
  - Отображение полигонов склада (проезжая часть `drivable`, здания `buildings`, запретные зоны `forbidden`, зоны ограничения скорости `speed_limit`, пешеходные переходы `crossing`, точки доков `warehouse`, `shop_a`, `shop_b`, `charger`).
  - Визуализация истинной позы робота с вектором ориентации и фантома оценки позы `pose_est` с вектором расхождения.
  - Динамическая отрисовка пешеходов с зонами предупреждения (радиус 3.0 м).
  - Лучи лидара и исторический след траектории.
  - Поддержка панорамирования (pan), масштабирования (zoom), центрирования по роботу и управления видимостью слоев.
- **Воспроизведение телеметрии (Replay Studio)**:
  - Проигрывание логов с шагом тика 0.1 с.
  - Управление воспроизведением (Play/Pause, покадровый шаг, переход в начало/конец).
  - Селектор скоростей: 0.1x, 0.5x, 1x, 2x, 5x, 10x.
  - Интерактивный таймлайн с маркерами нарушений.
  - Инспектор телеметрии: линейная/угловая скорость ($v, w, cv, cw$), статус (`moving`, `arrived`, `waiting`, `lost`, `estop`), текстовая причина замедления или остановки (`note`), дистанции до людей (`hum`) и препятствий (`obj`).
- **Реестр штрафов и инцидентов**:
  - Фильтрация по типам нарушений и стоимости штрафа.
  - Поиск по временным меткам и координатам.
  - Радарный снимок момента нарушения и контекстная телеметрия.
  - Быстрый переход к тику нарушения на карте с автоматическим замедлением.
- **Журнал миссий и доставок**:
  - Контроль точек погрузки/разгрузки, дедлайнов, эталонных дистанций.
  - Анализ точности удержания в доке (`max_hold_dist` при допуске `tol = 0.20 м`).
  - Диаграмма сопоставления фактического времени с эталонным и дедлайном.
- **Аналитика и скоринг**:
  - Разбор 100-балльной оценки по 6 блокам (Delivery, Efficiency, Safety, Rules, Pose, Collisions).
  - Радарная диаграмма показателей.
  - Метрики вычислительного бюджета контроллера (`step_time_ms`, порог 5 мс, время прогона).
  - Аудит песочницы (`sandbox_violations`, лог `stderr`).
  - Экспорт журнала инцидентов в CSV и отчета в JSON.
- **Центр запуска симулятора**:
  - Конфигурация сценария, контроллера и seed.
  - Эмуляция терминального вывода `python -m amrsim run`.
  - Индикатор прогресса и переход в плеер по завершении прогона.

## 2. Архитектура маршрутизации (Routing)

Приложение построено как SPA без сторонних серверных зависимостей. Маршрутизация реализована через хэш-роутер с поддержкой query-параметров.

| Маршрут | Модуль | Назначение |
|---|---|---|
| `#/dashboard` | `DashboardPage` | Общий мониторинг флота и статуса последнего запуска. |
| `#/replay` | `ReplayPage` | Студия телеметрии, 2D-карта и таймлайн воспроизведения. Принимает параметры: `t` (время), `x`, `y` (координаты центровки), `mission` (ID миссии), `run` (ID прогона). |
| `#/episodes` | `EpisodesPage` | Детальный аудит инцидентов. Принимает параметр `type` для предфильтрации. |
| `#/missions` | `MissionsPage` | Журнал транспортных задач. Принимает параметр `id` для фокуса на карточке. |
| `#/analytics` | `AnalyticsPage` | Разбор счета, диаграммы и выгрузка отчетов. |
| `#/runner` | `RunnerPage` | Интерфейс конфигурации и запуска симулятора. |

## 3. Стек технологий

- **Фреймворк**: React 19 (TypeScript)
- **Сборщик**: Vite 6
- **Стилизация**: Tailwind CSS 3
- **Рендеринг карты**: HTML5 Canvas API (аппаратное ускорение через 2D Context)
- **Иконки**: Lucide React

---

## 4. Модель данных

Приложение полностью автономно и работает в режиме Mock-first на базе схем симулятора `amr-1.0`:

- `src/mock/mapData.json`: векторная геометрия площадки из `samples/04_busy_yard.jsonl`.
- `src/mock/ticksData.json`: хронологический массив тиков телеметрии с сенсорами и координатами пешеходов.
- `src/mock/mockData.ts`: типизированные наборы данных для инцидентов, миссий, скоринга и аналитики.

Предусмотрена возможность загрузки пользовательских `.json` и `.jsonl` файлов через элемент интерфейса «Загрузить лог».

## 5. Установка и запуск

### Требования
- Node.js версии 18.0 или выше
- npm версии 9.0 или выше

### Шаги установки

1. Перейти в каталог фронтенда:
   ```bash
   cd frontend
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:3000`.

---

## 6. Сборка для продакшена

Для сборки оптимизированного статического бандла:

```bash
npm run build
```

Результат сборки помещается в директорию `frontend/dist/`.

Для проверки собранного бандла локально:

```bash
npm run preview
```
