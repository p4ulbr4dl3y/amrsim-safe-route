# Контроллер платформы AMR (Бэкенд)

Модуль управления автономным мобильным роботом для соревнования «Безопасный маршрут» (`amr-sim 0.2`, спецификация `amr-1.0`).

Контроллер получает на каждом тике (0.1 с) структуру сенсорных наблюдений `obs` (одометрия, IMU, лидар, ГНСС, параметры активной миссии) и возвращает кортеж параметров управления: `v` (линейная скорость), `w` (угловая скорость), `status` (состояние платформы), `pose_est` (оценка позы [x, y, theta]), `note` (текстовая диагностическая причина замедления или остановки).

---

## 1. Архитектура модулей

```
backend/
├── controller.py     # Главная точка входа Controller: конвейер обработки и оркестрация
├── geom.py           # 2D геометрия: отрезки, raycast, AABB, point-to-segment, полигоны
├── localize.py       # Локализация: EKF, скан-матчинг стен (Гаусс-Ньютон), ГНСС-гейт, dock-snap
├── perceive.py       # Восприятие: фильтрация снега/тумана, кластеризация, трекинг людей
├── route.py          # Планирование: Pure Pursuit, латеральный объезд препятствий, локальный A*
├── safety.py         # Безопасность: предиктивный гувернер скорости, TTC-модель, estop, note
├── APPROACH.md       # Краткое описание архитектурного подхода (критерий О1)
├── requirements.txt  # Зависимости среды выполнения (строго только numpy)
└── scenarios/        # Проверочные сценарии команды на краевые случаи (s1–s5)
```

## 2. Порядок вычислений в `step(obs)`

1. **Предикт позы**: кинематическая модель по одометрии и курсу IMU (`localize.py`).
2. **Коррекция позы**:
   - Скан-матчинг по контурам стен склада (метод Гаусса-Ньютона по векторным отрезкам стен `building_segs`).
   - Валидация и гейтирование измерений ГНСС по махаланобисову расстоянию.
   - Калибровка масштабного коэффициента одометрии при движении.
   - Доковый захват (`dock-snap`) при сближении с целевой точкой погрузки/разгрузки на расстояние $< 1.5$ м.
3. **Восприятие окружения (`perceive.py`)**:
   - Фильтрация ложных возвратов снега и шума тумана.
   - Кластеризация точек лидара и непрерывный трекинг препятствий в стабильном одометрическом базисе.
   - Оценка вектора скорости $(\vec{v}_x, \vec{v}_y)$, модуля скорости и курсового угла пешеходов с экспоненциальным сглаживанием.
4. **Планирование пути (`route.py`)**:
   - Отслеживание эталонной траектории миссии методом Pure Pursuit.
   - Расчет широкого латерального сдвига при обнаружении стоящих людей ($r \ge 1.5$ м, боковой зазор $\ge 4.2$ м) и статических препятствий.
   - В узких местах: безопасная уступка дороги с диагностическим статусом `waiting` и `note = "stop_person"`.
5. **Предиктивный гувернер безопасности (`safety.py`)**:
   - Ограничение скорости с учетом зон $v_{\max}$.
   - Расчет Time-To-Collision (TTC) и упреждающее плавное торможение с дистанции до 8.0 м.
   - **Принцип уступки пешеходу**: если пешеход движется навстречу или пересекает створ движения на дистанции 3.5–4.5 м, платформа полностью останавливается ($v = 0$). Внимательный пешеход не воспринимает стоящую платформу как помеху и беспрепятственно проходит мимо без замираний.
   - Аварийный останов `estop` при критическом нарушении зазоров.
   - Формирование диагностического поля `note` и статуса платформы.

## 3. Ограничения изоляции и зависимости

Реализация строго следует регламенту соревнования и правилам песочницы:
- **Зависимости**: разрешены исключительно стандартная библиотека Python и библиотека `numpy` (версия $\ge$ 1.24.0).
- **Запрещенные модули**: `scipy`, `numba`, `amrsim`, `threading`, `multiprocessing`, `ctypes`, `inspect`. Использование любого из них приводит к статусу `VIOLATION` и обнулению баллов за кейс.
- **Статическая изоляция**: контроллер не осуществляет дисковых операций ввода-вывода и сетевых вызовов в боевом режиме.
- **Вычислительный бюджет**: среднее время выполнения `step(obs)` составляет ~2.2 мс при жестком ограничении симулятора в 10 мс.

## 4. Команды проверки и тестирования

### Проверка правил изоляции
```bash
python -m amrsim check backend
```
*Ожидаемый результат: `0 violation(s) or error(s), 0 warning(s), result: OK`.*

### Запуск модульных тестов (163 теста)
```bash
pytest tests/
```
Для запуска сфокусированных наборов тестов:
```bash
pytest tests/test_controller.py      # Жизненный цикл Controller step()
pytest tests/test_safety.py          # Гувернер скорости, TTC и пешеходы
pytest tests/test_localize.py        # EKF, скан-матчинг, lost recovery
pytest tests/test_route.py           # Pure Pursuit и обход препятствий
```

### Запуск симуляции одиночного сценария
```bash
python -m amrsim run amrsim-participants/scenarios/01_clear.json \
  --controller backend/controller.py \
  --seed 7 \
  --report out/01_clear.json \
  --log out/01_clear.jsonl
```

### Запуск полного набора бенчмарков
```bash
python scripts/eval.py --controller backend/controller.py --seed 7
```
